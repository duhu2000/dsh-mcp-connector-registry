## 克而瑞卡片

可校验草案：[cric-deeplink-real-estate.json](connectors/cric-deeplink-real-estate.json)。
本机证据：[连接预检](evidence/cric-dsh-connection-preflight.md)。
鉴权采用 Bearer API Key，分类调研分析，标注付费服务。默认提示词提供具体问题，
不要求用户先填“研究问题”；不自动拆问、连续翻页或重试以免重复扣费。

官方文档将问数/问知区分，建议 600 秒客户端超时；Registry schema 当前不提供 timeout，
没有添加未支持的字段。与旧 `wuye-ai/mcp-server-wuye-ai` 物业知识库产品分别记录，不混用端点。
公开门户用户服务协议列示上海深度智联科技有限公司；包含账号自用及数据用途限制。
公开通用客户端接入说明不代表允许转售账号或再分发数据；条款适用范围仍须正式审核。

## 待补配置的中文卡片文案（非可安装描述符）

### 万方学术文献

- 提供方：万方数据；分类：调研分析。
- 描述草案：检索许可范围内的中文学术文献，辅助查找期刊论文及相关元数据。
  全文、引文和其他资源类型以实际 MCP 工具与账户授权为准。查询结果保留文献出处与检索时间。
- 示例一：检索 2024—2025 年中文期刊中关于动力电池回收的论文，最多列出 5 篇，给出标题、年份、期刊和来源链接；仅查元数据，不下载全文。
- 示例二：检索中文期刊中关于城市轨道交通客流预测的综述论文，最多列出 5 篇，说明检索条件和来源；不自动补查或下载全文。
- 尚不声明 OAuth 可直接接入；官网 API 的 X-App-Key 不能直接推定为 MCP Header。

### 森浦 qeubee 固收数据

- 提供方：森浦；分类：金融投资。
- 描述草案：面向固定收益研究的数据连接器候选，拟覆盖债券基础信息、发行与宏观资料；
  具体品种、行情时效及可用字段以官方 MCP 权限清单为准。
- 示例一：查询 2025 年 6 月发行的中国国债基础资料，最多列出 5 只，给出债券代码、期限、发行日期和来源；不发起交易。
- 示例二：查询 2025 年 6 月中国银行间债券市场交易日历，列出交易日及日历来源；不扩大查询范围。
- 技术状态：尚无足够证据填写正式 URL 或鉴权配置，保留文案不生成空壳卡片。

### 亿欧产业投融资数据

- 提供方：亿欧；分类：金融投资，企业数据作为标签。
- 描述草案：查询账户许可范围内的企业投融资事件，辅助比较产业赛道融资活动。
  返回结果需保留事件时间、金额币种、投资方及来源；未披露金额不作估算。
- 示例一：查询 2025 年 6 月国内具身智能领域的融资事件，最多列出 5 条，标明时间、轮次、披露金额及来源，不将未披露金额视为零。
- 示例二：比较蔚来与小鹏在 2024—2025 年已披露的融资事件，保留币种、事件日期与来源，不计算未披露金额。
- 官方公告要求 Client ID/Client Secret；完整 token 换取方式未知，暂不选择 api-key 或 OAuth 模式。

## query 凭据候选的中文文案方向

执中：卡片拟名“执中另类资产数据”，金融投资；聚焦 LP/GP/基金和出资事件，区别于通用工商查询。
示例：查询深圳市引导基金对外出资的基金，最多 5 条并保留来源；查询深创投管理的基金，最多 5 条并说明统计时间。

烯牛：卡片拟名“烯牛创投数据”，金融投资；聚焦投资机构、地区创投统计和基金/LP 能力，
与 IT桔子融资历史存在部分重叠，需评审增量。示例：查询 2025 年上海人工智能赛道的融资统计并说明口径；
查询深创投的基金管理信息，最多列出 5 项并注明来源。提示词仍需结合授权后的真实 schema 校对。

当前描述符 schema 没有 URL query 凭据绑定字段；未声明未经官方核实的替代 Header，
未把示例 Key 或占位 Key 填入市场 URL，也未安装第三方代理来绕过此限制。
