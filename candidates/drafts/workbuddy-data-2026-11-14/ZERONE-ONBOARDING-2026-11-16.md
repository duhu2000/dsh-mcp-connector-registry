## 客户端兼容性阻塞

用户提供的官方配置在 URL query 中传 `api_key`。v0.2.109 的市场 API Key 配置只绑定 Header，`credentialBindings` 只用于 stdio 环境变量；不能填成 `X-API-Key` 或 Bearer 冒充支持。

需要完成以下任一路径并做真实验收：

- 获得厂商明确支持 Header 的官方证据，并使用同一 Key 验证；当前无此证据。
- 实现 query Key 的安全绑定：公开描述符只保存干净端点、参数名及凭据引用；Key 在本机单独存储，请求发送时注入；检查 Host 动态配置、错误、重定向、重试、诊断、分享、编辑和备份的泄露风险。禁止将带 Key 地址写入公开卡片或提交。
- 官网提及 CLI，但未核实可分发包、版本、许可证或 stdio MCP 能力，不将普通 CLI 自动等同 MCP Server。

仅能匿名握手的连接不得标记为“Key 验证通过”。增加端点时不得静默扩大同一 Key 的发送范围。
