## 建议的“试试这样用”

### FRED 美国宏观经济数据

- 查询美国 2015—2025 年 UNRATE 与 CPIAUCSL 的变化，按月整理并比较趋势；列出每个序列的名称、频率、单位、季调状态、最新观测日期、来源和版权说明，不推断缺失值。
- 比较美国 2020—2025 年 FEDFUNDS 与 MORTGAGE30US 的变化，统一到月度口径并说明转换方法；保留 FRED 序列 ID、单位、观测期、发布日期、来源及版权限制。

### BIS 全球银行与金融统计

- 查询美国、中国、日本和德国最新可得的私人非金融部门信贷占 GDP 缺口，并回溯最近十年的季度变化；列出国家代码、频率、单位、观测期、BIS 数据流和原始国家来源，不补齐缺失值。
- 检索 BIS 中名义与实际有效汇率相关数据流，比较美国、中国和欧元区 2015—2025 年指数变化；先核对基期、频率和覆盖期，再列出序列键、单位、来源及不可直接比较之处。

### EIA 美国能源数据

- 比较加利福尼亚州与得克萨斯州 2020—2025 年居民零售电价的月度变化；先检索并说明所用 EIA API 路由、字段和州级维度，再列出单位、频率、缺失月份、数据来源和查询时间。
- 查询美国 2019—2025 年原油月度产量与商业库存变化，分别核对 EIA 路由、指标定义、单位和频率后再比较；标明时间范围、最新可得期、来源及不可直接推断的因果关系。

### USGS 全球地震目录

- 查询过去 30 天全球震级 6.0 及以上地震，按时间倒序列出 USGS 事件 ID、UTC 时间、地点、震级类型、深度、坐标、状态、更新时间和官方详情链接，并注明查询时间。
- 查询 2025 年日本本州中心点北纬 36.2、东经 138.3、半径 800 公里内震级 5.0 及以上地震，汇总数量和震级分布，并列出事件 ID、时间、深度、坐标、来源链接及目录可能修订的提示。

### PubMed 生物医学文献

- 检索 2022—2026 年 GLP-1 受体激动剂用于成人肥胖管理的随机对照试验和系统综述，列出 PMID、DOI、研究类型、发表时间、期刊、检索式、引用信息及开放全文可用性，不超出摘要或全文证据下结论。
- 检索 2020—2026 年家庭血压监测改善高血压控制效果的系统综述和荟萃分析，补充相关 MeSH 词并列出 PMID、PMCID 或 DOI、样本范围、主要结局、引用关系、来源链接和文章级许可。

## 审核结论与持续监控

- 五个 MCP 均来自 Official MCP Registry；FRED、BIS 与 USGS 端点由 Pipeworx 维护，EIA 与 PubMed 端点由 cyanheads 维护，均属于海外独立项目或第三方服务。
- MIT 或 Apache-2.0 仅证明 MCP 服务端源代码许可，不自动覆盖上游数据。FRED 序列版权、BIS 与国家来源署名、EIA 不背书条款、USGS 来源署名、PubMed 摘要和全文文章级许可已在卡片中分别提示。
- 卡片均明确“独立维护、非上游数据机构官方产品”，不得把 Official MCP Registry 收录误写成 FRED、BIS、EIA、USGS、NCBI、NLM 或 NIH 的官方背书。
- FRED 公共端点的通用只读问答已通过；部分直接 FRED 工具可能要求用户自己的 API Key。EIA 官方 API 通常要求注册密钥，但本次公开托管端点由服务方管理上游访问，二者均已披露。
- PubMed 与既有 Noodle 卡片侧重点不同：本卡片直接覆盖 PubMed、Europe PMC、MeSH、标识转换和开放全文可用性，Noodle 偏向 PubMed 衍生语义关联与引用网络发现。
- Pipeworx 三个端点包含共享网关通用工具；本次验收只调用与对应数据服务有关且明确只读的安全工具，后续按现有健康检查持续监控。
