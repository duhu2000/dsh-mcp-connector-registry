# 金数据表单 MCP：有限运行验收

验收日期：2026-09-20。审核人：`Duhu`。

## 已验证事实

- 官方[金数据 MCP 文档](https://open.jinshuju.net/mcp/)发布 `https://jinshuju.net/mcp` Streamable HTTP 端点；[OAuth 文档](https://open.jinshuju.net/mcp/oauth/)公布受保护资源元数据、动态客户端注册和 PKCE S256。
- 无凭据 `initialize` 返回预期的 HTTP 401；受保护资源和授权服务器元数据可读取。
- 在 DSH Web v0.2.51 当前 `workspace` 中以本机临时描述文件安装测试卡片后，界面显示“OAuth 已连接”；服务健康检查显示 `ok`。工具发现缓存显示 1 个服务、60 个工具，包含 `list_forms` 等查询工具，也包含创建、编辑、删除工具。
- 没有执行 `tools/call`，没有读取真实表单或提交数据，没有记录 OAuth Token、授权 URL 参数或任何个人信息。本机用于提供测试描述文件的临时服务已停止。

## 人工接受范围与残余风险

用户于 2026-09-20 明确决定将上述连接、健康检查与 `tools/list` 证据视为本次上架的**有限验收通过**，并授权合并发布。此决定不表示已实测业务查询，也不保证全部 60 个工具可在当前 OAuth scope 下调用。公共无凭据探针状态仍记为 `partial`，不能写成匿名业务可用。

DSH Web 测试时，创建、编辑、删除工具显示“已允许 · 默认策略”。卡片默认 OAuth scope 为 `public profile forms read_entries`，但工具可见不等于写入能力已被客户端治理层拒绝；仅需只读使用时，应在 DSH 工具治理中拒绝非必要工具。任何数据写入、删除、发布或外部发送都须由使用者确认。表单数据可能包含个人信息，不应把提交明细当作公开数据或在未核对授权的情况下送入模型。

金数据[使用条款](https://jinshuju.net/terms)要求用户对个人信息收集、使用及披露负责，并说明免费和付费套餐并存；实际权限、配额和费用以服务商与用户账号为准。本目录只提供连接描述，不复制、转售或背书金数据服务。
